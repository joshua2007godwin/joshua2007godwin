## 🚀 Featured Projects

### ⚡ IoT Smart Energy Monitoring System
Simulated smart meters streaming to AWS with real-time storage, threshold alerts, and a live dashboard.
- **Flow:** Python meter simulator → IoT Core → Lambda → DynamoDB → API Gateway → Next.js dashboard
- **Alerts:** SNS email notifications on abnormal consumption
- **Stack:** `AWS IoT Core` `Lambda` `DynamoDB` `SNS` `API Gateway` `Next.js` `Tailwind` `Vercel`
- 🔗 [Live demo](https://energy-dashboard-lyart.vercel.app/) · [Repo](https://github.com/joshua2007godwin/energy-dashboard)

### 🛡️ Real-Time Fraud Detection & Transaction Intelligence Platform
Streaming pipeline that classifies transactions as normal or suspicious using ML.
- **Flow:** API Gateway → Kinesis → Lambda (Python/ML) → S3/DynamoDB → Glue/Athena
- **Ops:** SNS fraud alerts, CloudWatch monitoring, IAM-secured
- **Stack:** `Python` `scikit-learn` `Kinesis` `Lambda` `Glue` `Athena` `SNS`
